# 方向评审（P-C2-review）

> 由 Claude 非交互评审产出（与改草案的 Codex 不同模型家族）。因 `Write(路径)` 写法未被 Claude CLI 识别，评审者只读不写，其标准输出由执行者原样存入本文件，仅去掉了"没有写文件权限"的开头与结尾两句。

**我没读 `workflow-manual.md`。** 附录 B 的内容我只按你的描述当作不动的前提。

## 第六类：过度设计

1. **自建 Funnel + 文件网关 + 短期凭证**（高，需要你决定）
   - Funnel 不适合给公开站出图，带宽限制不透明，域名是 `*.ts.net`，大陆能不能通要靠实测，无人值守也测不了。
   - 建议展示图和 Grok 上传改用 R2 或 Vercel Blob。预签名 URL 自带短期、单对象、限大小，撤下就是删对象，本地用 MinIO 就能自动测。
   - Contabo 只留签名/上传工作器和私有暂存。
2. **工作器的租约和续租**（低，可直接采纳）
   - 只有一个进程，用 `pg_advisory_lock` 就够。
   - 签名产物先落库再广播、唯一操作键、`tokenId` 派生这几条要保留。
3. **板块 4 的 ZIP 做成了版本化产品**（中，可直接采纳）
   - 改成按需生成、覆盖唯一一份，撤下或排除变更时直接删旧包。
   - 去掉复用任务、校验后替换和凭证撤销。
4. **HEIC 双路径加 T13**（中，可直接采纳）
   - 删掉 Grok 侧转换，原件一律上传，只在 Contabo 转。
   - 预编译版 `sharp` 通常不带 HEVC 解码，要实测，必要时换 `heic-convert` 或装带 libheif 的 libvips。
5. **手写登录和跨实例失败计数**（低到中，需要你决定）
   - 改用 Supabase Auth：关注册、预建一个维护者账户。
6. **香港代理那一节**（低，可直接采纳）
   - 从计划里删掉，只在 decisions 里留一句话。

## 其余五类

7. **Grok 是唯一收件通道，且是读不可信邮件的 LLM**（高，需要你决定）
   - 提示注入可以让它报假发件人，白名单判断全靠这个自报值。真实投递也没法无人值守地测。
   - 建议收信改走确定性入站（Cloudflare Email Routing 或 Postmark），转发 `.eml` 和 DKIM 结果，Grok 只负责提取日期和拒绝原句。
   - 若坚持纯 Grok，令牌权限限为只能提交事件。
8. **NFT 合约没人认领**（中，可直接采纳）
   - 没有 Foundry/Hardhat，板块 3 没有 `contracts/**`，部署和 owner 钥匙也没写。
   - 建议地基加合约工具链，部署作为 G2 的人工步骤，owner 钥匙不放服务器。
9. **「公开/可导出/可永久」的判断会在三个板块各写一遍**（高，可直接采纳）
   - `memorial`、`exports`、`permanent` 各自实现，迟早不一致，后果是把「不上链」的照片发出去。
   - 建议地基提供唯一的纯函数策略模块，带表驱动单测。
10. **`memorial` 太大，且和 G1 改同一批文件**（中，需要你决定）
    - 拆成 `review`（维护、审核、撤下）和 `public`（公开页面、媒体），G1 只改 `public`。
11. **缺字段就要回地基，再等你手动触发迁移**（高，需要你决定）
    - 这是夜里最大的卡点，AI 会搁置等你。
    - 推荐方案：允许板块追加自己前缀的迁移，合入 `integration` 时自动应用到测试库，生产仍由你手动触发。
12. **几个「待使用者决定」会让 AI 停住**（低，可直接采纳）
    - 包括专用系统用户、口令写法、T05 的托管 RPC。现在定好默认值写进计划。
13. **第一次真实 Turbo 和主网铸造前没有演练**（高，可直接采纳）
    - ArLocal 模拟不了 Turbo，SEMI App 也未必显示测试网 NFT。
    - 建议 G2 先做一次合成图烟雾：真实 Turbo 写入，主网铸一枚到你的钱包，在 App 里确认。执行时仍由你批准。
14. **自动审批没有数量上限**（高，需要你决定）
    - 钱包余额封得住花费，封不住被冒充发来的不当内容被永久上链。
    - 建议加每天或每封的数量上限。仅有自报发件人的投稿，只允许自动站内发布，永久操作转人工。
15. **§6 外部依赖漏项**（中，可直接采纳）
    - 异地备份目的地账号、买 Base ETH 的渠道、Turbo 余额低时的告警。
    - 还有 OP Etherscan key、Alchemy 账号。保留香港代理的话，还有腾讯云实名。
    - 大陆 ICP 备案：站点在 Vercel 和 Contabo，不涉及。
