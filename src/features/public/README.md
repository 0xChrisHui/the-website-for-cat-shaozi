# 公开时间线

匿名读取只接受现有真实业务入库来源 `stage0-grok`。样本存储与业务查询隔离。新增真实来源须先核实服务端来源约定，再纳入查询。公开样本生产者就绪后，通过地基的 `readPublicSample()` 校验签名票据，用经验证的 `runId` 从独立样本存储读取本轮已发布的投影。

当前版本由最大版本号决定。排序使用已经归一化为北京时间的日期（新到旧）、现有条目位置、收件时间和稳定 ID。当前表没有单独的维护者排序列，使用 `items.position` 表示稿内顺序。

照片目前只展示公开文案。媒体入口就绪后，通过站方 `/api/media/[itemId]` 提供展示副本。该入口须重新核验当前审批和逐项公开授权，并只在服务端使用当前版本的处理后媒体引用。
